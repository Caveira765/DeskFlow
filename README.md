## 🚀 Running the App

### Option A: Desktop App (Electron)
Double-click `DeskFlow.bat` or run:
```bash
npm run app
```

### Option B: Local Web Server
```bash
npm install
npm run dev
```
Open [http://localhost:5174/](http://localhost:5174/) in your browser.
